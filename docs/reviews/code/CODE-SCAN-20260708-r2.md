## 3. 机制侧修复（开闸暴露的潜伏缺陷）

| 项 | 裁定 | 依据 |
|---|---|---|
| `css-helpers.clampPxProp` 加严 px 判据 | 真实潜伏违规修复 | 旧码 `parseFloat("2.2em")=2.2` 会把 em 误夹成 `14px` 腐蚀值；output 相 clamp 先于 transform 运行会踩坑。改为仅夹纯 px（`/^-?\d+\.?\d*px$/`），放行 em/rem/vw/% 交由各自 transform |
| `scope/transform.ts` 多规则叠加 | 机制修复 | 旧码首匹配即止（`find`），output 相同一节点需多重 transform（em→px + svg 白偏移等）会漏。改为顺序应用全部匹配 transform 规则（各规则 matcher 一次，无 fixpoint 循环） |
